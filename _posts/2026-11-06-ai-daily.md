## 模型发布

### 1. OpenAI 发布 GPT‑6 Cyber，先向获批 Daybreak Red 客户开放

OpenAI 发布面向授权安全研究的 GPT‑6 Cyber，首批通过 API 和 Codex 向部分获批 Daybreak Red 客户提供。模型经过网络安全专项后训练，官方 ExploitGym 得分从上一代的 32.1% 升至 48.5%。访问仍需经过审批，测试结果来自官方受控环境。

- 系统卡将其描述为 GPT‑6 Astra 的网络安全专项版本，训练目标同时包含任务能力、遵守授权范围和准确报告结果。
- ExploitGym 衡量针对指定漏洞的任务表现。32.1% 与 48.5% 相差 16.4 个百分点，官方所称约 51% 为相对提升。
- 在加入范围外辅助服务的 Honeypot 评测中，未添加部署安全提示时越界比例为 0.07%，添加后观察为 0%。该结果采用特定评测条件。
- 官方按 Preparedness Framework 将网络安全能力列为 Critical。组织访问有身份与安全要求，API 默认要求 IP 白名单。

**为什么值得关注：** 安全团队可以把漏洞验证与补丁审查纳入获授权的隔离测试流程，同时记录目标范围和人工验收结果。

### 2. NVIDIA 开放四个 Cosmos 3 检查点，覆盖驾驶与双臂机器人场景

NVIDIA 为 Cosmos 3 Nano 增加四个开放权重检查点，分别处理离线驾驶数据、流式驾驶观测、模拟器画面转换和双臂动作视频预测。四个模型各有 16B 可训练参数，使用 OpenMDW1.1 许可。开发者可从这些领域适配示例继续后训练。

<figure class="snr-figure"><img src="{{ "/assets/figures/2026-11-06/2.svg" | relative_url }}" alt="Sim-Transfer 如何接入物理模拟器。策略给出动作 → 导出空间控制 → 生成 RGB 观测" loading="lazy"></figure>

- Transfer-Auto 可生成最多 11 路同步相机视角，并支持联合 RGB 与 LiDAR 生成。Sim-Auto 是其因果蒸馏后的流式变体。
- Sim-Transfer 从模拟器给出的深度、分割等空间控制生成 RGB 观测，物理状态由模拟器维护。
- Sim-Bimanual 从场景图像和机器人或相机动作生成后续观测，示例覆盖 YAM 与 AgiBot 双臂形态。
- 双臂发布示例要求 Linux、NVIDIA GPU、Docker 与 NVIDIA Container Toolkit。文档中的 vLLM-Omni 配置在单张 GB200 上测试，未给出最低显存规格。

**为什么值得关注：** 选择检查点时，需要先确定输入来自模拟器状态还是动作序列，再按自己的传感器与机器人形态验证适配效果。

来源：[NVIDIA Cosmos 3 发布与运行说明](https://huggingface.co/blog/nvidia/cosmos-interactive-world-simulation)

### 3. Google 推出 Gemini Omni 1.2 Flash，原生视频最长延长至 15 秒

Google 发布 Gemini Omni 1.2 Flash，提供原生最长 15 秒的视频生成和多轮对话编辑。相较 Omni 1.1 的 10 秒上限，新版支持更长片段与更强的参考素材遵循。官方公布 720p 每秒 0.07 美元的价格，较上一版下降 30%。

- 时长可在 3 至 15 秒之间按一秒递增指定。可先生成 360p 或 720p，再放大选中的成片。
- 参考输入可组合人物、产品与风格图像，最长三秒的动作片段，以及音频线索。
- 官方宣布在 Gemini API 和 Gemini for business 正式提供。Gemini 应用中的 15 秒视频正向 Google AI Ultra 用户推出。
- Google 仍在改进快速体育动作、快速脚本变化和复杂物理场景。输出携带 SynthID 水印。

**为什么值得关注：** 视频工作流可先核对时长、分辨率与参考素材，再用局部对话修改制作多个版本。预算按对应输出规格计算。

来源：[Google 发布、价格与产品范围](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/)

### 4. Gradium 详解 Phonon 端侧语音，31M 英语版采用 Apache 2.0

Gradium 发布 Phonon 的技术回顾，介绍两周前开放的端侧语音模型与推理方案。31M 英语版采用 Apache 2.0，40M 版支持五种语言，采用非商业许可。模型可在设备上生成语音，开发者可按单流延迟或批量吞吐选择推理实现。

- 模型覆盖英语、法语、德语、西班牙语和葡萄牙语，两个体积档约为 65 MB 与 75 MB，提供超过 100 个内置声音。
- ptts 面向设备单流推理，后端覆盖 CPU、Metal、WebGPU 和部分 NPU 等。Transformers 从 v5.21 提供参考 PyTorch 实现，支持批量生成与编译。
- 文章代码把 31M 生成模型和约 10.3M 参数的音频 tokenizer 分开列出，部署时需要同时核算相关组件。
- 40M 及其他非商业版本用于商业产品需另行授权。作者提供设备与榜单案例，本期未在本机复测。

**为什么值得关注：** 端侧语音选型需要一起检查语言、许可和完整组件体积，再测设备上的首段音频等待时间与持续生成速度。

来源：[Gradium 与 Hugging Face 技术回顾](https://huggingface.co/blog/phonon-tts)

### 5. LeRobot 0.7.0 加入交互式任务切换和远程策略推理

LeRobot 0.7.0 让运行中的机器人策略接收新子任务，并可通过文本问答或外部视觉语言规划器选择下一步。新版还支持直接流式读取机器人数据，以及将策略推理放到远程 GPU。模拟器接口与评测输出也做了统一。

<figure class="snr-figure"><img src="{{ "/assets/figures/2026-11-06/5.svg" | relative_url }}" alt="LeRobot 远程推理如何分工。本地采集观测与指令 → GPU 服务器运行策略 → 客户端对齐动作块" loading="lazy"></figure>

- 交互 rollout 保持机器人连接、权重和处理器加载。VQA 与自动选择子任务需要能输出文本的策略，或外部 VLM 规划器。
- 流式数据读取按需要请求视频字节范围，支持确定性恢复。训练栈增加 FSDP2、HSDP 与分布式检查点。
- 远程模式下相机、控制与录制留在本地，观测和指令发往策略服务器，动作块返回客户端。传输采用 Zenoh，提供 TLS 与访问控制配置。
- 新版移除旧 async_inference 模块，使用 remote 扩展。评测报告成功次数及 95% Wilson 置信区间。

**为什么值得关注：** 远程推理把机器人端与模型运行端分开，部署时可以分别测量控制周期、网络等待与动作块过期处理。

来源：[LeRobot 0.7.0 官方团队说明](https://huggingface.co/blog/lerobot/lerobot-release-v070)
