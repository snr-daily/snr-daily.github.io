## 模型发布

### 1. NVIDIA 公布 GR00T 2，五次示范微调后在 50 项任务上平均成功率达 95%

NVIDIA 在 CoRL 介绍 GR00T 2，一组同时预测未来画面和机器人动作的模型。团队在一台装有两只 Sharpa 手的机器人上评估 50 项任务；这些任务出现于其他机器人的数据或人类视频中，但未出现在目标机器人的训练数据中。作者报告，不微调时平均成功率为 40%，每项任务提供五次示范并微调后为 95%。

- 每项任务提供一次示范并微调时，平均成功率为 71%。五次示范的数据采集时间每项不到三分钟，单张 RTX 5090 上的 LoRA 微调约半小时。
- 零样本条件下，50 项任务中有 40 项至少成功一次；这个覆盖数与 40% 的试验平均成功率是两个口径。
- 预训练结合人类第一视角视频、手持夹具示范和跨机器人遥操作数据。项目页写明代码计划在 12 月提供。

**为什么值得关注：** 做机器人迁移评估时，可分别记录不微调、少量示范和微调后的成功率，再核算采集、训练和部署成本。当前数字限于作者所用机器人与任务。

## 研究

### 2. DeepMind 用 AlphaProof Code 验证 libsignal 编译代码的部分安全性质

Google DeepMind 公布 AlphaProof Code，一套由人制定证明目标、AI 生成证明、Lean 检查结果的验证流程。团队将它用于 Signal 参考实现 libsignal，在 AArch64 机器码层面证明 PQXDH 握手与 Triple Ratchet 的部分安全性质。证明只适用于指定实现、规范和假设，不能据此认定整个应用没有安全漏洞。

<figure class="snr-figure"><img src="{{ "/assets/figures/2026-11-11/2.svg" | relative_url }}" alt="AlphaProof Code 如何建立可检查的证明。定义证明目标 → 对指定编译代码生成证明 → Lean 检查证明" loading="lazy"></figure>

- 人类专家审查模型辅助起草的 Lean 规范，随后由 Gemini Carbon 驱动的多个 Agent 完成证明，最终由 Lean 内核检查。
- 论文报告约 650 万行经机器检查的 Lean 证明代码，依托约 2.6 万行受信规范和 AArch64 语义。行数反映项目规模，不衡量安全性。
- 官方称此次工作耗时四周。论文区分符号和计算安全保证，并对所依赖的密码原语、底层例程和对手模型作出限定。

**为什么值得关注：** 相比只验证协议设计，这类方法能把保证推进到指定的编译产物。复用结论时，仍需核对实际构建是否匹配论文中的产物，以及假设是否覆盖自己的风险。

来源：[DeepMind 发布说明](https://deepmind.google/blog/introducing-alphaproof-code/) · [论文、证明范围与限制](https://deepmind.google/documents/36/Formal_Verification_of_Signal_4.pdf)

## 开发工具

### 3. Google 扩大 Gemini 4 Carbon 访问范围，GitHub Copilot 同步接入

Google 将 Gemini 4 Carbon 扩大至付费 Gemini API 用户与企业，部分消费入口向 Google AI Ultra 用户逐步推出。GitHub 同日宣布 Copilot 接入，覆盖 Pro+、Max、Business 和 Enterprise。Copilot 按供应商标价进行用量计费，入口逐步开放。

- Google 公布的公开版 API 优惠价为每百万输入 2 美元、输出 10 美元；11 月 30 日优惠期结束后分别为 4 和 20 美元。
- Copilot 可用入口包括 VS Code、Visual Studio、Copilot CLI、网页、移动端和 Copilot coding agent，也包括 JetBrains IDE、Xcode 与 Eclipse。
- Business 与 Enterprise 管理员可通过模型策略管理访问；若全局默认开关未关闭且该模型未被单独禁用，新模型默认开启。
- 上述优惠价为 Google 公告中的公开版 API 价格；不同渠道的资格、账单与推出进度应分别核对。

**为什么值得关注：** 团队可先检查方案、管理员策略和模型选择器，再用已有任务对照结果与用量。无需把模型缺席直接判断为本地配置故障。

### 4. Anthropic 推出 Claude 白板和表格测试版，Claude Data 正式开放

Anthropic 将白板、表格与数据协作带入 Claude，三个功能面向付费方案。白板和表格处于测试阶段；原 Claude Dashboards 更名为 Claude Data 并正式开放。Data 的认证查询和实时共享仍处于测试阶段。

- 白板允许团队共同编辑；Claude 可整理便签、把讨论转成带负责人和日期的计划。
- Sheets 支持标签页、公式和下拉选项，可导出 XLSX 或 CSV。官方说明目前只提供基础表格功能。
- Data 需要数据连接器。实时共享的查看者可看到已批准查询的结果，但不能借用共享者的权限运行其他查询。
- Team 默认开启三项功能；Enterprise 默认关闭白板和表格，Data 将于 11 月 19 日默认开启，管理员可调整。

**为什么值得关注：** 引入实时共享前，可先验证查询授权和看板刷新频率。Data 正式开放并不意味着其每项功能都脱离测试阶段。

### 5. Google 新增 TPU 8tx 和 8i Max，分别面向机密推理与高带宽推理

Google 扩展第八代 TPU 产品线。8tx 以机密推理为重点，沿用 8t 芯片并配合第五代 AMD EPYC 主机和低延迟互连。8i Max 把两颗 8i 芯片放入同一封装，针对长上下文与机架计算密度。

- Google 称 8tx 在硬件层保护和隔离使用中的数据与模型权重，面向敏感数据推理，也可用于小规模训练。
- 8i Max 的计算能力、SRAM 和 HBM 带宽均为 8i 的两倍，属于官方硬件规格对比，不能直接换算为两倍端到端吞吐。

**为什么值得关注：** 选型时应先区分内存带宽和数据隔离两种需求。长上下文业务还需要以实际模型、并发数和缓存策略验证吞吐及延迟。

### 6. OpenAI 将于 2027 年 2 月 10 日从 API 移除 GPT Image 2

OpenAI 在 11 月 10 日的 API 停用文档中宣布弃用 GPT Image 2。模型别名和 2026 年 4 月的固定快照都将在 2027 年 2 月 10 日移除。官方列出 GPT Image 2.6 的 Sunburst 和 Flare 作为替代。

- 涉及两个模型标识：gpt-image-2 与 gpt-image-2-2026-04-21。
- 推荐替代标识为 gpt-image-2.6-sunburst 或 gpt-image-2.6-flare，两个旧标识的移除日期相同。
- 通知针对 API 模型；弃用公告日期与实际移除日期不同。本条报道新增的迁移期限，11 月 5 日期号已报道过 2.6 的发布。

**为什么值得关注：** 维护图像应用时，应排查代码、配置及批处理中的两个旧标识，预留验证时间，比较替代模型的输出和费用后再切换。

来源：[OpenAI API 官方停用日程](https://developers.openai.com/api/docs/deprecations#2026-11-10-gpt-image-2)
